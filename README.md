# AI Roles Academy

An interactive, self-contained LMS for the **AI Roles Skills Taxonomy** (AI Engineer / AI Architect /
Forward Deployed Engineer): 584 lessons across 30 modules and 3 tiers, each written reasoning-first
(why it exists, how it works, a concrete example, trade-offs, pitfalls, when to use, role lens, an
interview-style check question, and a 3-question quiz), plus a guide and capstone per module.

## Run it

    python3 scripts/build.py          # parse + validate content/, bundle site/data.js, write site/index.html
    node scripts/serve.js 8765 site
    open http://localhost:8765

Progress (learned lessons, quiz results, spaced-review schedule, notes, capstone checklists) is stored in
the browser's localStorage. Export/import it from Settings.

## Layout

    taxonomy.json              modules -> topics with stable ids (generated by scripts/make_taxonomy.py)
    chunks.json                work units used to generate content
    content/SPEC.md            authoring spec every lesson follows
    content/<module>/<slug>.md one lesson per topic; _module.md is the module guide
    scripts/build.py           validator + bundler (--check <files>, --check-module <id>, --report)
    scripts/make_workflow.py   emits scripts/lms-continue.workflow.js with only the lesson work still left on disk
    CONTINUE.md                handoff: state of the 584-lesson build and how to resume it locally
    site/page.html             app markup (artifact form); index.html is generated from it
    site/styles.css, app.js    the app
    site/data.js               generated bundle of all lessons

## Editing a lesson

Edit the Markdown, then `python3 scripts/build.py --check content/<module>/<slug>.md` until it prints ✓,
then rebuild. The format is documented in `content/SPEC.md`; `content/model-internals/kv-cache.md` is the exemplar.
